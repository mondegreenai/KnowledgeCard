# Changelog

All notable changes to the Knowledge Card format are recorded here.
This project follows semantic-style versioning; breaking schema changes increment the
minor version during the 0.x series.

## [0.1] - 2026-06

Initial public draft.

- Knowledge Card JSON Schema (2020-12) with seven blocks: meta, concept, entities,
  relationships, reasoning, boundaries, system link.
- JSON-LD context for the `kc:` vocabulary.
- Skeleton energy diagnostic ontology.
- Worked wind-energy example (gearbox outer-race spalling).
- Written specification.
- Card validator.
