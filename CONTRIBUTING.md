# Contributing to Knowledge Cards

Thank you for your interest in the Knowledge Card format. This is a v0.1 public draft, and
community input is exactly what it is published for.

## How to contribute

- **Feedback and proposals:** open an issue describing the problem or idea. For changes to the
  schema or specification, please open an issue to discuss before submitting a pull request,
  so the direction can be agreed first.
- **Example cards:** additional worked examples in new domains are welcome. Cards must validate
  against the schema (`python scripts/validate_card.py <card>`), be free of proprietary data,
  and cite representative rather than confidential sources.
- **Fixes:** corrections to the schema, context, specification, or documentation can be
  submitted directly as pull requests.

## Ground rules

- Keep examples free of confidential or proprietary information. Representative, published, or
  synthetic values only.
- A contribution is licensed under the same terms as the file it touches: Apache 2.0 for the
  schema, context, examples, and scripts; CC BY 4.0 for the ontology and specification.
- Be respectful and constructive. This is an open effort to establish shared structure, not a
  competition.

## What this project is not

This repository publishes the **open standard**: the schema, context, a skeleton ontology, and
worked examples. It does not contain Mondegreen's card-generation pipeline or the full domain
ontologies used in engagements. Contributions should concern the open format.
